# Zero-Crossing Time Bounds for the Homogeneous Super-Twisting Algorithm

This repository contains the supporting material for the paper:

**Zero-Crossing Time Lower Bounds for the Homogeneous Super-Twisting Algorithm**

Diego Gutiérrez-Oribio and Ioannis Stefanou

## Description

This work studies the time between consecutive zero crossings of the
sliding variable in the homogeneous super-twisting algorithm.

The main results provide lower bounds on the time required to complete
an excursion, estimates on the number of excursions above a prescribed
amplitude, and conditions on finite-time accumulation.

## Repository contents

- [Lean formalization](lean/): Lean 4 code supporting the algebraic
  results, including build instructions and verification details.

Additional numerical code and supporting material may be added later.
